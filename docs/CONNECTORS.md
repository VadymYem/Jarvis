# Конектори Jarvis | AuthorAi

Конектор — це окрема захисна межа між агентом і зовнішнім сервісом. Модель бачить лише вузький набір типізованих операцій; вона не отримує Android `Context`, OAuth-токен, пароль або shell.

## Поточні конектори

| Конектор | Реалізовано | Підтвердження | Дані доступу |
|---|---|---|---|
| Поштовий застосунок | Вхідні, видима чернетка, пошук/читання через Accessibility | чернетка, введення й натискання | зберігає сам поштовий застосунок |
| Termux | RUN_COMMAND, результат, обмежені ADB-операції, сценарії Jarvis | кожен запуск | Android permission `RUN_COMMAND` |
| Shizuku | дозволені системні ADB/shell-операції | залежно від ризику | дозвіл Shizuku |
| Нагадування | локальні одноразові фонові задачі | за політикою tool | локальне сховище WorkManager |

## Налаштування Termux

1. Установити актуальний Termux із F-Droid або офіційного GitHub release.
2. У Termux виконати `pkg install android-tools`.
3. Додати `allow-external-apps=true` до `~/.termux/termux.properties` і перезапустити Termux.
4. У Jarvis натиснути «Дозволити» біля `Termux / ADB` і надати `RUN_COMMAND`.
5. Для власних автоматизацій створити `~/.jarvis/actions/`, помістити туди executable-файл і видати йому `chmod 700`.

Jarvis підтримує `adb_devices`, `adb_connect`, `adb_disconnect`, `adb_force_stop`, `adb_keyevent` і `run_script`. Сирі `bash -c`, `sh -c` та довільний command text навмисно відсутні.

## Поштова модель безпеки

У 0.3.1 Jarvis не просить пароль від пошти й не містить спільного OAuth client secret. `EmailAppTool` відкриває системний поштовий застосунок. Для повного API-конектора кожен користувач проходитиме OAuth окремо, а refresh token зберігатиметься через Android Keystore. Доступ ділитиметься на мінімальні scopes: читання, чернетки й надсилання вмикаються незалежно.

Автоматичне надсилання листа не повинно бути наслідком простого prompt із листа або вебсторінки. Майбутня автоматизація з надсиланням матиме явне правило користувача, список дозволених одержувачів, журнал і можливість dry-run.

## Наступні конектори

1. Gmail API та Microsoft Graph: пошук, читання, чернетки, labels/folders і надсилання.
2. Google/Outlook Calendar: читання вільного часу, чернетка події, запрошення після підтвердження.
3. Google Drive, Dropbox/OneDrive: scoped пошук і робота лише з вибраними файлами або app folder.
4. Месенджери: офіційні API там, де вони доступні; інакше видима UI-автоматизація.
5. Загальний планувальник: тригер, умови, дозволені tools, ліміти, журнал і kill switch.
