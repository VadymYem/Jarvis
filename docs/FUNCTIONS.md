# Функції Jarvis | AuthorAi

## Реалізовано у версії 0.3.1

### Агентне ядро

1. Приймає завдання природною мовою українською або іншою мовою моделі.
2. Розкладає завдання на послідовність коротких дій.
3. Виконує одну дію за крок і перевіряє її результат.
4. Зберігає видимий журнал планів, дій, успіхів і помилок.
5. Зупиняє нескінченні цикли після 16 кроків.
6. Просить підтвердження для дій середнього й високого ризику.
7. Блокує критичні та невідомі системні операції.

### Локальні та хмарні моделі

8. Імпортує локальну модель у форматі `.gguf` через системний вибір файлу.
9. Перевіряє сигнатуру GGUF до запуску моделі.
10. Запускає локальну модель на пристрої через `llama.cpp`.
11. Працює локально без API-ключа та без надсилання промптів у хмару.
12. Підтримує Gemini API.
13. Підтримує OpenAI API та GPT-моделі.
14. Підтримує Groq API.
15. Підтримує довільні OpenAI-сумісні HTTPS API.
16. Зберігає окремі endpoint, модель і ключ для кожного провайдера.
17. Дозволяє перемикати рушій без перекомпіляції застосунку.
18. Не містить спільного або вбудованого API-ключа.
19. Шифрує особисті ключі через AES-GCM та Android Keystore.
20. Не включає ключі або локальні моделі в Android backup.

### Взаємодія з Android

21. Відкриває встановлений застосунок за назвою або package name.
22. Читає семантичне Accessibility-дерево поточного екрана.
23. Маскує парольні поля до передавання хмарній моделі.
24. Шукає й натискає елемент за видимим текстом.
25. Вводить текст у вибране або активне поле.
26. Прокручує доступну область вперед.
27. Виконує системні дії «Назад» і «Додому».

### Shizuku / ADB

28. Визначає наявність і стан Shizuku.
29. Запитує дозвіл Shizuku штатним системним діалогом.
30. Запускає власний UserService з UID `shell` або `root`.
31. Примусово зупиняє пакет після підтвердження.
32. Відкриває дозволені сторінки Android Settings.
33. Надсилає дозволені key events: Back, Home, Enter, Tab, media та volume.
34. Надає або відкликає runtime permission після підтвердження.
35. Змінює дозволений `system`, `secure` або `global` setting після підтвердження.
36. Читає стан активного Activity через `dumpsys`.
37. Не виконує довільний shell-текст від моделі.
38. Передає команду як масив аргументів, що блокує shell injection.
39. Обмежує виконання системної команди 15 секундами.
40. Обмежує розмір поверненого системного виводу.

### Автоматизації

41. Створює локальне нагадування із заголовком і текстом.
42. Працює з нагадуваннями у фоні через WorkManager.
43. Показує нагадування у власному Android notification channel.

### Інтерфейс і приватність

44. Нативний Material 3 UI на Jetpack Compose.
45. Фірмова тепла палітра AuthorChe замість стандартної теми.
46. Автоматична світла й темна тема.
47. Edge-to-edge компонування для сучасних Android.
48. Український інтерфейс за замовчуванням.
49. Відображення стану Accessibility та Shizuku.
50. Окремий діалог підтвердження з рівнем ризику.
51. Захищене маскування API-ключа у формі.
52. Дані Accessibility не записуються на диск за замовчуванням.

### Голосовий режим і пошук телефона

53. Приймає голосові команди через вбудований у Android SpeechRecognizer.
54. Вибирає on-device розпізнавач, коли він доступний на пристрої.
55. Показує частково розпізнаний текст безпосередньо в MD3-інтерфейсі.
56. Розпізнає локальні швидкі команди українською, російською, англійською та німецькою.
57. Повідомляє час і заряд батареї без запиту до LLM.
58. Передає довільну голосову фразу в агентний цикл як повноцінне завдання.
59. Озвучує локальні та модельні відповіді через Android TTS.
60. Виконує «Джарвіс, де ти?» до звернення до LLM.
61. Шукає точний файл `Downloads/was-wollen-wir-trinken.mp3` через MediaStore.
62. Відтворює сигнал циклічно на максимальній гучності alarm stream, вібрує і потім відновлює попередню гучність.
63. Дозволяє зупинити пошук у застосунку або постійному foreground-сповіщенні; через 15 хвилин зупиняється автоматично.
64. Зберігає приватний URI еталонного запису голосу для підключення справжнього локального clone-TTS.
65. Може бути вибраний системним цифровим помічником Android і починає слухати після `ACTION_ASSIST`.

### Сервіси, пошта й Termux

66. Визначає наявність поштового застосунку й показує стан конектора.
67. Відкриває основну поштову скриньку для подальшого пошуку та читання через Accessibility.
68. Перевіряє адреси одержувачів і відкриває заповнену чернетку через `ACTION_SENDTO`/`mailto:`.
69. Не надсилає чернетку приховано; натискання кнопки й введення тексту потребують підтвердження.
70. Визначає наявність Termux і запитує небезпечний Android-дозвіл `RUN_COMMAND` лише за дією користувача.
71. Запускає Termux-команди офіційним `RUN_COMMAND` Intent і отримує результат через `PendingIntent`.
72. Повертає агенту обмежені `stdout`, `stderr`, exit code та опис помилки.
73. Підтримує `adb devices`, connect/disconnect, force-stop і дозволені key events.
74. Запускає користувацькі executable-сценарії лише з `~/.jarvis/actions/`.
75. Передає Termux-аргументи масивом і не приймає довільний shell-текст від моделі.
76. Вимагає підтвердження для кожної Termux/ADB-операції.

## Заплановано

### Надійність і моделі

77. Постійне Room-сховище задач із відновленням після перезапуску.
78. Нативний tool calling для Gemini та OpenAI-сумісних провайдерів.
79. Кілька моделей на провайдера, автоматичний failover і контроль лімітів.
80. Окремі planner, executor, validator і reflector.
81. Профілі підтверджень: кожна дія, вся поточна задача, постійне правило.
82. Керування context window, KV-cache, температурою та кількістю потоків локальної моделі.
83. Завантаження сумісних GGUF-моделей із перевіркою контрольної суми.

### Повна Android-автоматизація

84. Жести й координатний fallback, коли Accessibility-вузол відсутній.
85. OCR і vision-аналіз знімка лише на запит.
86. MediaProjection після системної згоди на кожну сесію.
87. Точні, повторювані та умовні автоматизації.
88. OAuth-конектори Gmail, Outlook, календарів, дисків і месенджерів з окремими scopes.
89. Робота з файлами через Storage Access Framework.
90. Контакти, календар і повідомлення через окремі дозволені tools.
91. Локальна черга довгих задач і відновлення після перезапуску телефона.

### Голос

92. Локальний wake word із постійним видимим foreground-індикатором.
93. Справжній локальний clone-TTS із підтримкою української, німецької й англійської.
94. Видимий запис голосових нотаток, запущений самим користувачем.
95. Локальна транскрипція та резюме запису.
96. Політика автоматичного видалення сирого аудіо.

Прихований запис телефонних дзвінків не входить до плану: звичайний Android APK не має привілейованого `CAPTURE_AUDIO_OUTPUT`, а запис без інформованої згоди створює юридичний і приватнісний ризик.
