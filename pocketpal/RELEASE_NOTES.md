# Jarvis | AuthorAi 0.16.0

- Прибрано окрему сторінку «Агент». Команди, інструменти й дозволи збережено.
- У звичайному чаті з’явився перемикач Work: створення проєкту, перевірка, виправлення та повторна перевірка.
- Прогрес зберігається перед дією і після результату. Перерване завдання можна продовжити кнопкою «Продовжити Work».
- Фоновий Android-сервіс утримує процесор активним із вимкненим екраном; модель не вивантажується під час задачі. У сповіщенні доступна зупинка.
- Вибір одного, кількох або всіх ZIM-паків застосовується до нативного індексного пошуку й читання статей.
- Для моделей без native tool calling використовується перевірений JSON-протокол із grammar та перевіркою аргументів. Для Mamay у Work застосовано рекомендовані параметри генерації.
- Контекст локальної моделі рахується її GGUF-токенізатором після форматування, з урахуванням Vision. Український текст перевіряється на round trip.
- Веб-пошук: паралельні джерела, резервні канали, українські відмінки, джерела для read_url, короткий кеш. HTTP-відповіді обмежуються до передачі в JS.
- HTML перевіряється в Android WebView: console errors, мобільна ширина, реальний знімок. Якщо модель підтримує Vision, вона отримує знімки для оцінки.

Перевірки документів, зображень і коду перелічуються у звіті. Автоматичний звіт не означає перевірку всіх інтерактивних сценаріїв або відсутність усіх можливих помилок. Фонову роботу та Vision потрібно перевірити на реальному пристрої зі встановленою моделлю й mmproj. Якщо Android примусово завершує процес, завдання відновлюється зі збереженого прогресу після відкриття застосунку.
