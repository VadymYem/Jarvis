# Jarvis | AuthorAI 0.7.0 — тестовий arm64 APK

Jarvis працює з локальною GGUF-моделлю або налаштованим сумісним сервером. Для Wikipedia потрібен окремий архів ZIM: у Налаштуваннях відкрийте «Офлайн-бібліотека», завантажте український архів із каталогу Kiwix і оберіть файл. APK не містить самих статей. Після підключення пошук у ZIM автоматично додає до контексту релевантні уривки перед відповіддю моделі, без мережі.

## Що перевірити

- Jarvis Live слухає репліку, зупиняє мікрофон на час обробки й озвучення відповіді, потім починає слухати наступну репліку. Кнопка зупинки завершує сеанс. Локальна доступність розпізнавання залежить від мовного пакета Android. Для українського озвучення слід завантажити модель Supertonic у застосунку.
- Окремий режим агента та дії телефону (Shizuku, ліхтарик, Accessibility, Termux) прибрано.
- Веб-пошук пробує Bing RSS, потім DuckDuckGo HTML; можна налаштувати власний SearXNG або провайдера з ключем.

## Відомі межі

Публічні пошукові сервіси можуть повертати 403; тоді застосунок повідомляє про помилку, а не вигадує результати. Телефон не містить повного інтернет-індексу. Wikipedia ZIM оновлюється окремо від APK.
