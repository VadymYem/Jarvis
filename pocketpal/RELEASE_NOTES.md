# Jarvis | AuthorAi 0.17.0

- Звичайні повідомлення й переклад не використовують JSON-протокол інструментів. Відповідь знову надходить поступово без завантаження схем усіх дій.
- JSON-дії локальних моделей обмежені схемою без повторного застосування lazy grammar шаблону. Повні службові обгортки моделі обробляються; довільний HTML чи JSON усередині пояснення не запускає інструмент.
- Work більше не вимагає створювати файли для звичайного запитання. Якщо файли потрібні або вже створені, перевірка залишається обов’язковою.
- Статті за замовчуванням вимкнено. Вибір конкретних паків або «Усі паки» вмикає їх явно; «Вимкнути статті» прибирає їх з пошуку і доступних дій Work. Явний @Вікі працює офлайн.
- Вбудовані Jarvis, Lookie та Перекладач позначені значком і написом «Вбудований» у списку PAL та перемикачі чату. Позначка прив’язана до ID і зберігається після перейменування.
- PAL «Перекладач» починає нову розмову з визначення двох мов, перекладає в обидва боки, пояснює значення, граматику й наводить приклади. Використовує поточну модель без обов’язкового завантаження іншої.

## Перевірка на телефоні

1. Вимкнути Work і статті. Надіслати звичайне українське повідомлення: має бути поступова відповідь без помилки JSON.
2. У Work попросити створити HTML-файл із українським текстом. Перевірити реальний файл і відсутність помилки Unexpected character: <.
3. Увімкнути один ZIM-пак, перевірити джерела; вимкнути статті й перевірити їх відсутність у наступних відповідях Work. Для явного офлайн-пошуку використати @Вікі.
4. Відкрити «Перекладач», написати «Працюємо з німецькою та українською», потім «vermeiden». Перевірити переклад, пояснення і приклади; надати українське слово для зворотного перекладу.
5. У новому чаті перекладача задати іншу пару мов. Перевірити, що попередня пара не переноситься самовільно.

Автоматичні перевірки протоколу й маршрутизації не вимірюють швидкість конкретного GGUF на телефоні та не оцінюють лінгвістичну точність моделі. Ці сценарії потребують перевірки встановленого APK.
